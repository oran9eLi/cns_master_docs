延时器 ​

适用：v0.1.0-alpha · GNU Radio 3.10.12.0
模块类型：delay · 模块定义版本：6

是什么 ​

让输入数据推迟若干 item 后出现在输出中，用于研究时间差、相位差和多路对齐。每对输入／输出独立通过同一个延时量，延时不会改变长期采样率。

典型接线 ​

第一路使用 上游.out → 延时器.in，取 延时器.out；增加端口对后使用 in2 → out2 等对应路径。dly 是消息输入，不能接数值流。

下表为内置默认参数下的端口。带路数、元素类型或 vlen 的模块会随参数改变流端口。

方向端口数据类型单位 / 形状
输入in（输入）numeric_f64归一化幅度；vlen=1
输入dly（dly（消息））message消息；不计入流路数
输出out（输出）numeric_f64归一化幅度；vlen=1

参数怎么用 ​

延时按 item 计。标量时，一个 item 是一个数；向量时，一个 item 包含整组分量，延时会一起移动这组数据。延时时间等于延时 item 数除以 item 采样率。

各端口对采用相容的数据形状；改变向量长度不能当作改变延时单位。起始处的填充区与后续推迟的真实输入要分开观察。

内置默认值如下；本机设置可为新实例指定其他默认值，打开已有工程保留工程参数。

参数内置默认值取值与约束修改时机
延时采样数
delay_samples		0范围 0 至 2147483647可在线应用
输入／输出对数
num_ports		1范围 1 至 1024；当前画布支持 1–1024 路。修改后须重新准备，缩减前请先解除相关连线和工具绑定。重新准备
每个 item 的向量长度

元素类型
element_type		numeric_f64实数 float32 (numeric_f64)；有符号 int16 (int16)；有符号 int32 (int32)；无符号 byte (byte_u8)重新准备

在线修改与重新准备 ​

运行中可在线应用以下字段组；同组字段一起提交：

  • delay_samples

其余计算字段需停止并重新准备。在线应用以该节点实际回执为准；编辑草稿本身不会改变已运行的图，旧缓存仍可能包含修改前的数据。

改变延时量会改变流内部状态，观察切换附近的实际输出，不假定存在已标注的精确样本边界。端口对数、类型或向量长度改变后重新准备。向 dly 发送整数是一次运行时消息，保存工程不会自动重发。

常见问题 ​

四分量向量延时 1 是移动一个分量吗？ 不是，移动一个完整 item，即一整组四个分量。

改了参数但时间轴没有整体平移？ 延时器改变输出数据内容；Master 保留输出自身的逻辑时间轴，不替你移动横轴。
