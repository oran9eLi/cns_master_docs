从录制的 GPS 信号算出位置 ​

地面站地图上的无人机位置，从哪里来？机载导航接收机接收卫星信号并算出经纬度，再由飞控把定位结果送给地面站。本课从接收机这一环开始，用保存下来的 GPS 信号算一次位置。

运行示例 ​

  1. 确认导航实验环境显示 环境已就绪。
  2. 点击 Master 左侧的 导航，打开 录制信号定位。画布上有两个模块，GNSS 录制信号源的“录制文件”输出接到 GNSS 接收机的“录制文件”输入。信号源的“原始 IQ 样本”保留为 内置定位样本。
  3. 按 F5 运行。第一组坐标需要等接收机找到足够的卫星、读出卫星发来的信息之后才会出现。样本读完，实验自动结束，本次结果可以继续查看。

GNSS-SDR 读取样本时会先从录制的数据里搜索卫星信号，再跟踪每颗卫星信号的变化，读出导航电文并估计信号传播的时间。接收机把多颗卫星的观测组合起来，求出自己的位置。录制文件里的 I、Q 是同一时刻的一对信号数值，也就是接收机拿到的原始输入。这段样本记录了约 100 秒的卫星信号。GNSS-SDR 首次定位样本

用观察器读坐标和点分布 ​

通过 编辑 → 插入 → 观察器 添加工具。打开观察器的 参数页，在捕获变量输入框中输入下表里的变量名，从下拉结果中选择来自当前工程的 GNSS 接收机输出。点击 添加捕获变量 可增加输入。

想看什么绑定变量怎样读图
接收机在哪里绑定“纬度”“经度”，也可添加“高程”。切到 输出页查看坐标，纬度和经度用度，高程用米。
每次算出的点怎样分布用另一台观察器，先绑定“东向偏移”，再绑定“北向偏移”。在 输出页选择 XY 关系图。横轴向东，纵轴向北，单位都是米。原点对应本轮算出的第一个定位点，图上的每个点对应一次定位结果。

先记录一组经纬度，再看散点是集中在一小片区域，还是在某个方向上铺得更宽。把点分布与两个轴的刻度结合起来，就能估计这段样本的定位结果在水平方向散开了多远。

另存为自己的工程，改一个参数再试 ​

  1. 用 文件 → 另存为… 保存一份自己的工程。
  2. 点击画布上的 GNSS 接收机，保持样本和其他参数不变，只把 多普勒搜索上限从 10,000 Hz 改为 9,500 Hz。
  3. 按 F5 再运行一次，比较两轮能否得到定位结果、散点的分布有没有明显变化。

卫星与接收机的相对运动会使接收到的频率产生偏移。调低搜索上限后，接收机检查的频偏范围缩小。信号的频偏超出搜索范围时，接收机就可能找不到这颗卫星。对照时把每轮的参数、是否求得位置和点分布一起记录下来。
