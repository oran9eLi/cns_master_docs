低空通信、导航与监视：从状态回传开始 ​

无人机的高度、速度和位置，怎样出现在地面站？这条学习路径从这个问题开始。你只需会读坐标、做乘除，不必先学通信原理、复数或傅里叶变换。遇到新词，先看它在本课解决什么问题，再动手验证。

适用 CNS Master v0.3.0-alpha，PC 本地 GNU Radio 仿真。下载工程不需要实验箱、飞控、服务器或账号。这里讲的是通信信号的基础模型；位置数据的传输与计算位置的方法不同，通信部分先研究信号传输模型；新增的导航与监视部分使用平面测距和延迟模型，不做真实卫星定位、电台收发或雷达采集。

按什么顺序学 ​

每次只做一课。先写下自己的预测，运行后再用坐标和数据解释观察结果。01 建立全貌，02—06 认识实数信号，07 再引入两个坐标，08—09 走两条不同的调制／判决入门路线。

顺序低空应用问题本课完成的事
01 链路全貌地面站读到高度，要经过哪些环节？区分数据、信号、网络与显示；可选运行一段简单处理链。
02 幅度、频率与相位怎样准确描述通信中的周期变化？对照两路波形，分别改变高低、快慢和起始位置。
03 采样计算机怎样表示连续变化？数每周期的点，解释四点折线为什么不是三角波。
04 三种观察视图一条波形里同时有几种变化？把时域的起伏、频谱的峰与瀑布的频率轨迹对应起来。
05 噪声接收信号为什么不再平滑？将随机变化与有规律变化相加，比较噪声幅度。
06 滤波怎样保留一部分变化、压低另一部分？比较低通前后的两个频率，认识滤波的限制。
07 I/Q一个数不够表示幅度和相位时怎么办？从平面坐标理解 I/Q，认识旋转方向和星座视图。
08 调频与解调数值怎样控制信号的转动快慢？让常量控制频率，再用相邻样本的角度变化还原数值。
09 码元与判决离散数据怎样选一个信号点？用 QPSK 映射和理想硬判决，区分索引、坐标与比特。

08 的模拟调频与 09 的离散码元映射分别学习，不把前者自动当成后者的完整收发机。

从信号实验走向定位与监视 ​

完成通信入门后，可继续三课；也可直接从熟悉的平面坐标进入第 10 课。

顺序低空应用问题本课完成的事
10 三段距离求位置已知无人机到三个锚点的距离，怎样求位置？由勾股定理生成距离，再解回二维坐标。
11 相关找延迟怎样知道一段接收信号比参考晚了多久？移动短序列手算相关，读出峰对应的 lag。
12 延迟换距离怎样把样本延迟换成米？先换算秒，再区分单程和往返传播。

第 10 课独立完成，第 11、12 课连续学习。相关器以 N 点为一帧，本课采用 N=8、参考源样本数 Q=64；Q 须至少为 N 且能被 N 整除，不自动补尾。位置与距离向量须显式选择分量；完整相关帧使用单路 lag 显示。它们是 PC 教学模型，不能仅凭模型中的峰判断发现真实目标。

第一次操作先看这里 ​

  1. 下载某课的 .cnsproj，放到个人文件夹。启动 Master，准备就绪后点击“进入”；用“文件 → 打开工程”（Ctrl+O）选择文件。安装版请使用程序内打开。
  2. 工程已保存模块、接线和观察器绑定。通过“视图 → 分析工具”找回仍存在的观察器窗口。在“参数”页核对捕获变量；如果自己重建，从“编辑 → 插入 → 观察器”创建窗口，在输入框键入节点名，从候选中确认它的输出。多路时点击“添加捕获变量”，最多 4 路。
  3. 通信入门 01—09 课建议先把流程图的“参考源样本数”设为 4096，按 F5 运行。状态完成后看实际缓存；不是打开工程就有预制结果。Ctrl+F5 只准备，不会产生运行数据。要持续看瀑布，设 0 后运行，最后按 Shift+F5 停止。
  4. 图上的横轴默认是样本时间，单位秒（s）；纵轴按本路实际单位读。点“自动刻度”恢复范围，也可用刻度旁的 +／−。滚轮缩放，Shift＋滚轮只调横轴。运行中拖动回看会保留一段当时数据，点“自动刻度”／“自动范围”回到最新数据。
  5. 做对照时先 Shift+F5 停止，只改指定的一个参数，再按 F5。这样避免把旧缓存误当成新参数结果。保存对照工程用“另存为”（Ctrl+Shift+S），保留原文件作参照。

新准备会清空上次数据；重新打开只恢复配置和已有运行快照，不恢复样本或进程。普通关闭观察器会移除该实例及其绑定，工程因此未保存；需要暂时让开时可最小化窗口。切换到其他工程时当前任务继续运行；运行另一个工程会先结束前一个任务。关闭工程时按程序提示处理未保存内容与关联工具。

先记住四种不同的量 ​

量本课程中的含义不要混淆
信号频率 f，Hz一秒重复多少个周期不等于每秒传多少条高度消息。
采样率 Fs，sample/s一秒给同一路信号取多少个数本组标量工程每个 item 就是一个样本；不是画面刷新次数。
幅度相对参考大小，本组多为归一化幅度没有标定时不能称为伏特、米或发射功率。
码元索引从若干种选择中选第几个，09 中为 0—3不是模拟幅度，也不是一条完整的遥测报文。

阅读曲线时问自己：输入来自哪个节点？坐标是什么？运行的是哪组参数？若三点不清楚，先回参数页核对。教程中的静态参考曲线用于解释一组实际计算结果，Master 的实时图仍来自你本次运行。点击参考图可单独打开原始 SVG，再用浏览器缩放读清坐标与样本点。

做完短实验以后 ​

能解释每课的对照结果后，再读模块手册，按需要查完整参数与限制。原有综合示例仍从模块文章下载：例如实数处理用于串联运算与三种滤波，复数与 I/Q串联复数处理，QPSK 与信道增加信道影响。信道有原生前视，不能直接按输入输出同索引判错，先读该模块的说明。

可以把不同短实验组合成自己的工程，但先一次增加一个环节，并保留处理前的观察分支。得到一张好看的图以后，还要能说明它能证明什么、不能证明什么。
