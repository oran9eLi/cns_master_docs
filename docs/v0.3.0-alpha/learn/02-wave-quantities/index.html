02 用高低、快慢和起点描述信号 ​

适用 v0.3.0-alpha。先会读01 的时域坐标，本课只需乘除和角度常识。

低空应用问题与学习目标 ​

机地通信要用可区分的信号表示信息。如果只说“波形变了”，接收端很难知道究竟变了什么。本课用两路同样的正弦波建立参照，再分别认识幅度、频率、相位，为调制实验准备词汇。

周期 T 是重复一次所需的时间，单位秒；频率 f 是每秒重复的次数，单位 Hz，T = 1/f。幅度描述相对中线的最大偏离，不能把峰到谷的差值叫作幅度。相位描述一个周期内所处的位置：整圈 360° 对应 2π rad，四分之一圈为 π/2 rad ≈ 1.570796 rad；rad 是弧度单位。

接线与参数理由 ​

下载 02-wave-quantities.cnsproj

text
信号源 1 out ──→ 观察器：参照波
信号源 2 out ──→ 观察器：实验波

两路不相加，各自直接观察。同一软件运行中以各自第 0 个样本为起点；这不是两台独立无线设备已经完成同步。

两个源的初始设置数值原因
波形／幅度／偏置正弦／1／0让中线为 0，区分幅度与偏置。
频率64 Hz周期 1/64 s = 15.625 ms。1 ms = 0.001 s。
初相位0 rad起初两路重合，便于与后来的变化比较。
采样率1024 sample/s每周期 16 点，本课不同时改变取样疏密。

逐步操作 ​

  1. 打开下载工程；在观察器参数页确认信号源 1、2 的 out。需要叠加时，用“添加捕获变量”选第二路，模式为时域叠加。
  2. 设每路 4096 样本，按 F5。停止后将横轴缩到约 0.0625 s，应见四周期；纵轴先自动，读出 ±1。
  3. 记录基准图：两路周期相同且重合。若要按样本起点比较相位，查看从 0 s 开始的数据，或比较同一时刻的两个波峰，别把拖动窗口造成的平移当成相位改变。
  4. 按下面顺序做三次对照。每次先停止、恢复信号源 2 的初始值，再只改一个字段，重新 F5。信号源 1 始终保持初始值。
  5. 用“另存为”保存自己的一个对照版本；记录修改字段、轴刻度与解释。

单参数对照与预期图像 ​

本图显示基准和“只改幅度”的实际对照；后面的频率、相位练习分别重跑，不是在这一轮中同时改变三项。

每次只改信号源 2 的一项先预测，再核对
幅度 1 → 0.5峰谷约 ±0.5，周期仍 15.625 ms，过零位置与参照相同。
频率 64 → 128 Hz同一段 0.0625 s 内由 4 周期变为 8 周期，幅度仍约 1。
初相位 0 → π/2 rad频率仍 64 Hz，初始样本从 0 变为约 +1；实验波相对参照提前四分之一周期，即 3.90625 ms。

正相位使本例的正弦在同一时刻更早走到峰值。若把相位看成“横向移动”，必须同时说明比较参照与方向。恒定相位差不改变频率；下一课会看到取样点也会改变折线外观。

也可用公式检查：x(t) = A × sin(2πft + φ) + offset。不必先会推导，只要对应 A 为幅度、f 为 Hz、t 为 s、φ 为 rad；例如 t=0、φ=π/2 时，sin(π/2)=1。公式描述本课理想正弦，不把所有通信波形都当成一条正弦。

常见问题 ​

现象解释与处理
相位填 90 后现象不对字段单位是 rad，90° 应填约 1.570796，90 rad 不是四分之一圈。
把幅度 1 读成 2从 −1 到 +1 是峰峰值 2，幅度仍是 1。
改相位后频谱主峰仍在 64 Hz恒定相位只改起点，本课幅度谱不显示该相位差。
改频率后峰值略低于 1样本未必恰好落在峰顶；先读每周期点数，不把折线最大值当成连续波的精确峰值。
改草稿后曲线没变本课统一停止再运行，不用旧缓存判断新参数是否生效。
