v0.3.0-alpha 模块教学文档 ​

已发布版本。适用 GNU Radio 3.10.12.0。

获取软件 ​

v0.3.0-alpha 已发布，为 Alpha 测试版。 安装包通过产品交付渠道提供，本教学站公开提供模块文档和实验工程。对应版本源码与构建说明向软件接收者提供。

本版本目录包含通信、导航与监视模块。从左侧目录选择模块，先看接线和观察方法，再按参数表调整实验。文章按模块类型编写，同一类型的多个实例共用。

没有通信基础，从这里开始 ​

低空通信、导航与监视学习路径从无人机状态回传切入，依次认识幅度、频率、相位、采样、时域／频谱／瀑布、噪声滤波、I/Q 与基础调制判决。每课只研究少量概念，提供独立工程、操作步骤和单参数对照；原有综合工程继续保留在模块文章中。

先做一次实验 ​

  1. 从模块文章下载 .cnsproj，在 Master 的“文件 → 打开工程”载入。
  2. 从“编辑 → 插入”打开观察器，在参数页选择文章指定的输出。
  3. 需要调整频谱时，打开“运行 → 频谱设置…”，选择 FFT 长度、窗函数和重叠比例，点击“应用”。
  4. 按 F5 运行；Ctrl+F5 只准备，Shift+F5 停止当前本地任务。
  5. 保存工程会保留图、参数与已有运行快照；重新打开不会恢复样本或运行进程。

本站示例均为 PC 本地仿真。阅读网站需要网络，本地实验无需登录或联网。

从调频与判决开始 ​

新增的调频、幅相分解、正交解调和二值判决可以串成一个小实验。进入这些文章可下载调频与判决示例 modulation-chain.cnsproj，并查看各模块的具体接线与观察步骤。

示例以 4096 Hz 采样率送入常量 1，调频灵敏度为 π/8，预期产生模长约为 1、频率约 +256 Hz 的复数信号。先选择调频输出观察复数频谱，再分别选择幅相分解的两路输出，比较恒定包络与绕回的主值相位。

正交解调倍率取 8/π 时，预期首项为 0，后续解调值约为 1。二值判决把零和正值均判为索引 1，再经 BPSK 映射得到复数点 +1+j0。这条链便于区分模拟幅度、相位 rad、解调值和码元索引：它们的数据含义不同，不能仅因为显示为数字就互换使用。

如何读参数表 ​

表中默认值是内置默认，不会覆盖你的本机设置或已有工程。“可在线应用”须显式应用并查看节点回执；其余字段先停止、重新准备。同组参数、端口类型和实际采样率须满足文章说明的关联约束。

numeric_f64 / complex_f64 是 Master 通道标识；当前 GNU 原生浮点流分别为 float32 / complex64。整数和 byte 保留原生宽度。向量的一个 item 含 vlen 个分量，采样率和样本数按 item 计算；数值工具须显式选择分量。

设置整个工程的频谱 ​

打开工程后，从“运行 → 频谱设置…”进入“频谱分析参数”对话框。频谱配置属于当前工程，统一作用于本次任务全部非码元输出；同一路输出的观察器共用这份实际频谱。码元索引不生成模拟幅度频谱。

选项可选值怎样理解
FFT 长度 N256、512、1024、2048、4096、8192每个窗口使用 N 个连续 item；频点间隔为实际输出采样率 Fs 除以 N。
窗函数矩形、周期 Hann、周期 Hamming、周期 Blackman–Harris决定窗口内样本的加权方式，影响谱峰宽度与泄漏；后三种均采用周期形式。
重叠比例0%、50%、75%相邻窗口共用的样本比例；比例越高，帧间隔越短，实际采样率保持不变。

内置默认配置如下；未带频谱设置的旧格式工程采用相同的固定兼容值。

字段内置默认值
fft_length1024
overlap_percent0
windowhann_periodic
派生步长 hop_length1024 item

点击“应用”会将选项写入工程草稿，下次准备时生效。运行中的任务继续使用已经准备的实际配置；要采用新配置，先停止，再重新准备和运行。新准备会重新累计频谱窗口。

工程保存草稿配置，并在实际运行快照中分别保留当次实际配置；后续编辑不会改写旧运行的含义。旧历史没有记录的频谱配置保持未记录，不用新默认补成已知实值。重新打开工程恢复配置与已有快照，开始新的运行后才会产生新的样本和频谱。

频率与幅值怎么读 ​

每个输出使用自己的实际采样率 Fs，抽取、插值、映射或信道速率变化后的输出应按各自 Fs 读谱。相同 N 不代表不同输出具有相同的 Hz 刻度。向量按分量分别变换：每个分量都使用连续 N 个 item，vlen 不会把窗口的时间长度乘大。

实数频谱从 DC 到奈奎斯特，共 N/2+1 个频点；复数频谱为移频双边谱，共 N 个频点，从 −Fs/2 起。两者的频点间隔都是 Fs/N。幅值按窗系数之和归一化，实数仅对非 DC、非奈奎斯特频点倍增；复数不套用这项单边系数。

纵轴表示线性峰值幅度，不是功率或功率谱密度（PSD）。选择 FFT 长度、窗和重叠只改变频谱分析方式，时域样本与实际采样率保持原值。比较不同设置时，先核对频率刻度、窗口长度和幅值定义。

窗口时长与帧间隔 ​

设步长为 H，H = N × (100 − overlap_percent) / 100。窗口时长是 N/Fs，相邻帧的间隔是 H/Fs；有重叠时，这两个时间不同。第 j 帧（j 从 0 开始）覆盖 item 区间 [jH, jH+N)，起始时间为 jH/Fs。

一路输出已经发布 S 个 item 时，预期完整窗口数为：S 小于 N 时是 0；否则是 1 + floor((S − N) / H)。各输出按自己的样本数、Fs 和窗口累计，不能拿一路的帧数代替另一路。这是由完整窗口推导的数量，不是历史中额外保存的实际接收计数。

不足一个完整窗口的尾段不补零、不生成频谱；尾段仍属于时域输出。缩短传输批次或刷新观察器不会把这些尾样本变成完整窗口。

与滤波器的设计窗区分 ​

这里的窗用于观察频谱。低通、高通、带通模块中的 window 和 window_param 用于设计滤波抽头，决定模块实际怎样处理信号；它们的选项和参数含义见各模块文章。调整工程的频谱窗会改变观察方式，调整滤波器的设计窗则会改变滤波结果，两处设置分别保存、分别应用。

从距离与延迟认识导航和监视 ​

  • 三段距离求位置：坐标发生器 → 测距模拟器 → 二维定位解算器。
  • 相关找延迟：同一序列分为参考与延时分支，由相关器观察正负 lag。
  • 延迟换距离：相关器 → 峰值检测器 → 测距器，分清样本数、秒数与米数。

这三组实验共享同一张流程图和观察器。坐标与测距是局部平面软件模型；相关使用完整有限窗口，不代表真实 GNSS、雷达或设备采集。

多工程与慢速观察 ​

左侧“文件”列出已经打开的工程，点击即可切换。通信、导航和监视栏提供各自模块，均可拖入同一工程。任意时刻只运行一个实验：切换工程不停止当前运行，运行另一个工程会先结束前一个任务。

PC 软件仿真可在准备前选择 0.1×、0.25×、0.5×、1×，新工程默认 1×，运行中保持所选倍率。慢速改变计算推进的墙钟节奏，样本时间、采样率与频率含义保持原值。
