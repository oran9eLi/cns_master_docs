增益器 ​

适用：v0.3.0-alpha · GNU Radio 3.10.12.0
模块类型：gain · 模块定义版本：5

是什么 ​

对每个输入值乘以一个固定系数，输出与输入保持相同的 item 速率和向量形状。正系数改变大小，负系数还使实数波形反相。

典型接线 ​

信号源.out → 增益器.in。把信号源输出和增益器输出分别送到观察工具，即可比较幅度与相位；向量点表源也可接入匹配形状的增益器。

下表为内置默认参数下的端口。带路数、元素类型或 vlen 的模块会随参数改变流端口。

方向端口数据类型单位 / 形状
输入in（输入）numeric_f64归一化幅度；vlen=1
输出out（输出）numeric_f64归一化幅度；vlen=1

参数怎么用 ​

增益是乘法系数，不是 dB 数。若希望幅度变为原来的两倍，使用系数 2；负系数使波形围绕零翻转，零系数输出零。

整数元素要求整数增益，并保留相应原生整数类型。向量输入的每个分量使用同一个系数，不会分别设置每分量增益。

内置默认值如下；本机设置可为新实例指定其他默认值，打开已有工程保留工程参数。

参数内置默认值取值与约束修改时机
增益

每个 item 的向量长度

在线修改与重新准备 ​

运行中可在线应用以下字段组；同组字段一起提交：

  • gain

其余计算字段需停止并重新准备。在线应用以该节点实际回执为准；编辑草稿本身不会改变已运行的图，旧缓存仍可能包含修改前的数据。

在线修改后，从真实回执和后续曲线确认效果。改变元素类型或向量长度需要重新准备，不能用增益设置隐式完成类型转换。

下载与观察 ​

实数信号、分支运算与三种选频滤波 ​

下载 real-processing.cnsproj

在 PC 上打开工程，按 F5 运行。有限运行可将参考源样本数设为 2048 item；重新打开工程后需再次运行以取得数据。

实数信号、分支运算与三种选频滤波

  • 64 Hz 与 768 Hz 混合信号分支进入低通、高通、带通；比较增益、相乘、8 点延时与两抽头 FIR。

int16 向量 item、双端口延时与流标签 ​

下载 vector-items-tags.cnsproj

在 PC 上打开工程，按 F5 运行。有限运行可将参考源样本数设为 2048 item；重新打开工程后需再次运行以取得数据。

int16 向量 item、双端口延时与流标签

  • 每个 item 有 4 个 int16 分量；1 item 延时移动整组分量。标签 offset=1 表示第 2 个 item，显式选择第 3 分量观察。

实数处理示例把信号源 1 接到增益器，输出应为原波形的两倍。向量示例则对整组 int16 分量乘以 2；在变量选择中明确选定同一下标，再比较处理前后。两组均为本机仿真。

常见问题 ​

调大增益后波形看起来一样高？ 图表自动纵轴可能同步放大范围，比较读数或使用相同的手动刻度。

整数输入为什么不接受小数系数？ 该路径采用整数增益；需要小数运算时，从相容的实数源和数据类型开始搭图。
