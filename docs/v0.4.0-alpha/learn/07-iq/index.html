07 用两个坐标表示信号：I/Q 与圆周上的点 ​

接收设备处理无线信号时，常用一对同时刻的数保留幅度和相位信息。为什么不只用一条上下起伏的曲线？先在纸上画一对坐标轴：一个点的位置需要“横着多少”和“竖着多少”两个数。本课从这幅图理解 I/Q，不要求先学复数运算。

适用 CNS Master v0.4.0-alpha。先完成02 幅度、频率与相位以及04 不同观察方式。

下载本课工程：07-iq.cnsproj

学习目标与必要知识 ​

  • 把一个复数样本读成同一时刻的坐标对 (I, Q)。
  • 区分 I/Q 时域、星座与频谱三个视角。
  • 通过正、负频率对照，理解只看 I 可能丢掉什么。

I 是横坐标，也叫实部；Q 是纵坐标，也叫虚部。I+jQ 是把这一对数写在一起的记号，j 满足 j²=-1。本课不需要展开复数乘除。

点到原点的距离表示幅度，例如 (1,0)、(0,1)、(-1,0) 距离都为 1。点的方向表示相位：一整圈是 2π rad，约 6.283 rad；四分之一圈是 π/2 rad，约 1.571 rad。I 和 Q 各自有正负号，都不能单独当作“幅度大小”。

接线与参数理由 ​

text
复数信号源 1.out ──→ I/Q 分解器 1.in
        │                   ├─ i：横坐标 I
        │                   └─ q：纵坐标 Q
        └── 同一个复数样本可直接用 I/Q 时域或星座观察
位置本课值为什么选它
复数信号源 1cosine；频率 +64 Hz；幅度 1；初相 0；实、虚偏置均为 0产生 I=cos(φ)、Q=sin(φ) 的单位圆周信号
采样率1024 Hz每转一圈有 1024÷64＝16 个样本，便于认识离散位置
I/Q 分解器 1向量长度 1每个 item 就是一对 I、Q，分解后仍是每秒 1024 对相应样本

这里每个采样时刻只产生一个复数样本，其中 I、Q 同时存在。分解器不会另生成一条“延迟后的 Q”，也不把采样率翻倍。

逐步操作 ​

  1. 下载工程。停止其他本地任务后，Ctrl+O 打开文件，选中复数信号源核对上表。先画出 (1,0)、(0,1)、(-1,0)、(0,-1) 四个位置。
  2. 按 F5。工程已保存复数 I/Q、星座及分解后两路的观察器。参数页中，I/Q 和星座观察器均只捕获“复数信号源 1 → 输出”。
  3. 在第一个观察器的“输出”页选“I/Q 时域”。把显示范围缩到约 0.03125 s，能看到约两圈对应的两组周期曲线。图例中两条曲线是同一复数样本的两个分量。
  4. 在星座观察器选择“星座”，查看横轴 I、纵轴 Q。使用等比例坐标，或“自动刻度”恢复合适范围；横纵缩放不等会把圆看成椭圆。
  5. 对照分解器的两个实数输出：在其观察器参数页确认捕获为“I/Q 分解器 1 → I”和“→ Q”，输出页用“曲线叠加”。它们应与复数 I/Q 显示中的两个分量分别对应。
  6. 想自己绑定时，从“编辑 → 插入 → 观察器”新建。在参数页输入节点名，点选普通复数输出的候选；只留这一条捕获，才能选择 I/Q 时域或星座。不要把复数源和分解器两路塞进同一个观察器。
  7. 可另开单路观察器，绑定“复数信号源 1 → 频谱”，在频率横轴寻找 +64 Hz。完成后 Shift+F5 停止，保留本轮数据查看。

图像为什么这样 ​

右图的横纵轴采用相同比例，每个点由同一时刻的 I、Q 组成。数一数圆周上的位置，再回到左图找到对应时刻的 I、Q 值。

I、Q 时域都按 64 Hz 周期变化，但峰谷出现位置不同。星座图把“同一时刻的 I 和 Q”作为一个点，不再以时间作为横轴。本例应看到半径约 1 的圆周上的 16 个离散位置；点很多时仍可能重叠在这些位置。它们不是连续画出的模拟轨迹。

这幅圆周散点图使用了“星座”显示方式，但信号源此时没有发送四种离散数据，所以不能把它叫作 QPSK 数据星座。下一节中的离散码元映射才规定“哪个点代表哪个编号”。

复数频谱可以区分旋转的方向：本例主峰在 +64 Hz。这里的正负频率是相位随时间转动方向的表示；不是说真的存在一个“负的无线电发射频率”。

单参数对照：+64 Hz 改为 −64 Hz ​

  1. 停止，只改复数信号源的“频率”为 −64 Hz，其他值保持不变，按 F5 重新运行。
  2. 对比同一采样位置的 I、Q：I 的余弦值相同，Q 的正负方向反过来；复数频谱的峰应移至 −64 Hz。
  3. 查看星座散点位置。它仍是同样的圆周位置集合；一张没有时间顺序的静态散点图不能单独告诉你转动方向。应结合 I/Q 时域或频谱判断。
  4. 恢复 +64 Hz，再运行一次。

请解释：如果只留下 I 那条曲线，为什么这两个实验条件难以区分？答案应同时提到本例的初相条件和 Q 中保留的方向信息。

常见问题 ​

现象检查方法
I/Q 或星座选项不可选必须恰好捕获一路普通复数输出，不能是频谱、实数，或混入其他捕获
看到椭圆先核对横纵轴比例，再核对幅度和实、虚偏置；不要立即当作信道失真
星座不是四个点本例是旋转单音，16 点一圈；它没有执行四点码元映射
星座不显示转动动画散点位置可能重复，且显示不保留箭头；用 I/Q 时间变化或正负频谱判断
Q 被当成幅度而出现负值Q 是有符号坐标；真正的幅度是点到原点的距离

本例没有无线电本振、天线、传播信道或硬件采样。它建立的是复数表示的数学直觉。接下来先用调频与正交解调认识一种“把值放进信号、再取出来”的方法。
