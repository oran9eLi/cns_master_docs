09 从数据编号到星座点，再作出判决 ​

无人机的电池状态、速度或位置可以先表示成数字，再按通信协议组织、编码并发送。本课只取其中一小步：假设数据已变成 0、1、2、3 四种编号，怎样把编号变成信号坐标，再从坐标判回编号？

适用 CNS Master v0.4.0-alpha。先完成07 I/Q。本例输入是软件生成的随机编号，没有真实电池值、坐标数据或通信报文。

下载本课工程：09-symbols.cnsproj

先认识比特、码元与星座 ​

比特（bit）只有 0、1 两种值。两个比特可以组合成 00、01、10、11 四种情况。发送端若把四种情况分别指定给四个信号状态，每选一次状态，就发送一个码元。

本课用 0—3 作为码元的编号，即码元索引。编号不是信号幅度：索引 3 不表示“幅度为 3”。星座点是与编号相对应的 I/Q 坐标。映射按编号查点；硬判决则从收到的坐标选择最近的已知点，只输出编号。

本例采用 QPSK 四点星座。若明确按 00→0、01→1、10→2、11→3 组织，每码元可以表达 2 bit；工程本身只处理编号，不自动打包比特。与之相比，BPSK 只有两个状态，每码元可表达 1 bit。状态数增加并不自动保证实际链路更快或更可靠。

接线与参数理由 ​

text
随机码元发生器 1.out → 符号映射器 1.in
                              out → 复数增益器 1.in
                                               out → 符号判决器 1.in
位置本课值为什么选它
随机码元发生器 1QPSK；最小索引 0（包含）；最大索引 4（不包含）；固定种子 7产生 0、1、2、3 四种编号，重新准备可从同一随机起点比较
码元率1024 符号/s每秒产生 1024 个编号；本课每码元映射为一个复数样本
源、映射器、判决器均为相同 QPSK 预设；D＝1使用同一套编号与坐标定义，避免表的含义不一致
复数增益器 1增益实部 1，虚部 0，向量长度 1基线不改变坐标；稍后只缩小坐标距离

QPSK 预设点表按编号排列如下。0.7071 是 1/√2 的近似值，每点到原点的距离约为 1。

编号IQ方位
0−0.7071−0.7071左下
1−0.7071+0.7071左上
2+0.7071−0.7071右下
3+0.7071+0.7071右上

表的顺序也有意义。四个点摆在相同位置、却给它们不同编号，接收端仍可能判回错误的数据。

逐步操作 ​

  1. 下载工程。Shift+F5 停止其他本地任务，用 Ctrl+O 打开。检查源、映射器和判决器均使用 QPSK；不要只检查其中一个。
  2. 先画出上表四个点，并预测输入索引 2 应落在哪一象限。再按 F5 运行。
  3. 输入／判决的观察器参数页应捕获“随机码元发生器 1 → 码元输出”和“符号判决器 1 → 码元输出”。输出页用“曲线叠加”，缩短横轴范围查看约 0.016 s 的数据，逐个读 0—3 的索引。
  4. 另两个观察器分别只捕获“符号映射器 1 → 星座输出”以及“复数增益器 1 → 输出”，在输出页选“星座”。每个星座观察器只留一路复数捕获，分别采用相同轴范围和等比例显示。
  5. 若自行重建，用“编辑 → 插入 → 观察器”，参数页输入节点名并点选候选。“添加捕获变量”用于把输入和判决两路放到一起；码元输出不选择频谱，星座观察器也不添加第二路。
  6. 运行后 Shift+F5 停止，查看保留数据。相同时间位置上的输入与判决编号应相同；完全重合时图上可能只看出上层那条颜色，结合图例确认两路确实绑定不同节点。
  7. 对照星座的点位与编号表，说明“0—3 的时间序列”和“四个 I/Q 点”是同一批信息在不同处理步骤的表示。

预期图像与解释 ​

右图把增益为 1 和 0.5 的星座放在同一坐标范围中，便于比较半径。下载工程中的两个星座观察器各显示一路复数来源，比较时也应使用相同轴范围。左图的输入编号与判决编号重合，可继续沿时间轴检查其他样本。

随机输入图按时间在 0、1、2、3 之间跳变。映射后的星座图应聚集为四个离散位置，不是上一课复数单音的圆周点集。判决输出在本课理想条件下恢复原编号。

图上点之间若有连线，那是显示方式，不表示本例实现了平滑的点间过渡。本课每个码元只取一个离散坐标，尚未加入把离散样本变成适合实际传输波形的脉冲成形，也没有无线电载波、接收同步或报文解析。

码元率为 1024 符号/s；在约定每符号 2 bit 的理想编号关系下，对应 2048 bit/s 的未计开销映射速率。这不能直接称为无人机可用数据吞吐量：真实报文、编码、同步和重传等还会占用资源。

单参数对照：只把增益实部改成 0.5 ​

  1. 停止，将复数增益器 1 的“增益实部”从 1 改为 0.5；虚部仍为 0，其他参数不变，按 F5。
  2. 在同样的轴范围下比较增益前后星座：后者 I、Q 绝对值约为 0.3536，点到原点的距离约为 0.5，仍分别位于原来的四个象限。
  3. 比较输入与判决索引：在本例没有噪声、没有旋转、正实数缩放的条件下，判决仍应一致。解释为什么“点没有落在原预设位置上”不一定导致判错——最近的那个点仍是同一个编号。
  4. 恢复增益实部 1，重新运行，再把工程另存为个人练习。

不要将这条结论推广为“信号再弱也不出错”。本例缩小坐标时没有额外加入接收噪声；真实信号减弱而噪声不随之等比例减小时，判决条件会改变。也不要只改一个模块为 BPSK 就沿用其余 QPSK 设置；更换码元体系需要整条链一致，本课不把它当作单参数练习。

常见问题 ​

现象检查方法
只出现两三个点先检查随机区间是否仍为 [0,4)，再检查是否只保留了很少样本
星座位置对，判回编号错核对源、映射器、判决器的模式、点表顺序、D 和归一化；位置集合相同不代表编号相同
想看码元的模拟频谱但没有候选编号是离散选择，不能直接当模拟幅度；可观察映射后的复数频谱，但要说明未成形的离散模型
星座选项不可选恰好捕获一路复数输出；索引输出属于码元类型，不能用星座显示
加入信道后逐项比较出现差异本课没有信道节点；综合示例中的原生信道存在前视，必须先核对时间／索引对应关系，不能直接算误码率

你现在已经区分了“数据内容—码元编号—复数坐标—接收判决”。回到学习路径，可选择保留的 QPSK 综合工程继续研究信道；其中的额外行为应按该例说明核对，本课的理想直连结论不自动适用。
