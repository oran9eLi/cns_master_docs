01 从三个距离找到平面位置 ​

适用 CNS Master v0.4.0-alpha。先手算预测，再运行工程，对照结果。

低空应用问题与学习目标 ​

训练场需要知道无人机在场地平面上的位置。如果已知无人机到三个固定点的距离，能否反推出它在哪里？本课先在电脑里用已知位置生成距离，再由距离求回位置，检查这条计算链是否讲得通。

完成本课应能区分坐标和距离，解释为什么要约定锚点顺序，并能用一个参数的变化预测位置与测距的变化。这是局部平面测距模型，不是无人机实飞或真实 GNSS 定位。

开始前需要什么 ​

会读平面直角坐标，能做平方、开平方和简单代入即可。不要求先学卫星导航。实际操作使用 v0.4.0-alpha 或包含这些模块的后续版本。

打开本课工程 ​

下载 01-position-from-ranges.cnsproj

在程序中用“文件 → 打开工程”（Ctrl+O）选择下载文件。工程已保存模块、接线及下述观察器；也可按接线图自行重建。打开后先核对参数，再准备和运行，文件不保存上次的样本缓存。

数学小回顾：距离画成圆 ​

在场地选一个原点，约定 x、y 的正方向，单位都用米。点 P=(3,4) 表示从原点沿 x 方向走 3 m，再沿 y 方向走 4 m；它不是经纬度，也不包含高度。

到锚点 A=(a,b) 的平面直线距离为：

text
r = √[(x-a)² + (y-b)²]

这就是勾股定理。只知道一个距离时，点可能在以锚点为圆心的整条圆上；两个距离可能对应两个交点。第三个不共线的锚点进一步约束位置。

本课采用三个锚点：A1=(0,0)、A2=(10,0)、A3=(0,10) m。将距离公式分别平方，再相减，可以消掉相同的 x²+y²：

text
20x = r1² - r2² + 100
20y = r1² - r3² + 100

这里的 10 和 20 都来自本课的锚点布置，不能照搬到其他站位。

接线与理由 ​

text
坐标发生器.position → 测距模拟器.position
测距模拟器.ranges   → 二维定位解算器.ranges

坐标发生器.position   → 观察器：已知模型位置
定位解算器.position   → 观察器：解算位置
定位解算器.residual   → 观察器：距离残差

前两条是流程图模块连线；后三条表示观察器捕获对应输出，不是额外的计算模块端口。

position 的一个 item 是同一时刻的 [x,y]，两个分量单位为 m。ranges 的一个 item 是同一时刻按 A1、A2、A3 排列的三个距离，不能把三项当作三个先后时刻。模拟器与解算器分别保存锚点参数，本课必须显式设为相同的六项列表；程序不会替使用者同步。

先在波形观察器中捕获源位置和解算位置的各两个分量，共四路，比较同一坐标的两条曲线是否重合。再开一个观察器，对解算器的同一个位置输出分别选择分量 0 作为 x、1 作为 y，使用 XY 显示；两个分量必须来自同一时刻。

本课设置与操作 ​

先用静止、无噪声的情形理解距离与位置的关系。下表列本课需要填写的设置；完整参数范围见模块手册。

本课设置值与理由
坐标发生器 sample_rate_hz10 Hz，每秒产生 10 个位置 item，相邻历元间隔 0.1 s。
坐标发生器 x0_m、y0_m3 m、4 m，便于用 3、4、5 勾股数组检查第一路距离。
坐标发生器 vx_m_s、vy_m_s均显式设为 0 m/s，本课先观察静止点。新建实例可能带有非零速度，必须核对这两项。
模拟器与解算器 anchors_m均设为 [0,0,10,0,0,10] m，依次表示三个锚点的 x、y。
模拟器 noise_std_m、seed0 m、0，基准先关闭测距噪声。
解算器 max_residual_m1 m，作为距离一致性门限；它不是位置误差保证。

按以下顺序操作：

  1. 新建工程，加入三个模块并按上图连接。逐项填写本课设置，尤其检查两个速度为零及两份锚点一致。
  2. 设置观察器：源位置与解算位置的 0／1 分量共四路叠加；另一个观察器用解算位置的 0／1 分量查看 XY。查看三个距离时，分别显式选择 ranges 的 0、1、2 分量；残差直接选标量输出。
  3. 图底部“参考源样本数”填 64，本课将产生 64 个位置历元。先准备，检查准备结果，再运行；准备成功时还没有本次样本，运行后再记录数据。
  4. 记录任务状态、距离、位置和残差，再与下节手算值比较。静止位置的 XY 数据应集中于一个点；若重合点不易看清，用分量读数核对，不应期待移动轨迹。
  5. 等本轮任务完成，只进行下一节指定的单参数修改，重新准备并运行。用本次运行的数据判断变化，不把旧显示缓存当成新参数的结果。

预期结果：曲线与数值怎样读 ​

将 P=(3,4) m 代入，三个距离应为：

text
r1 = √(3²+4²)     = 5 m
r2 = √[(3-10)²+4²] = √65 m ≈ 8.0623 m
r3 = √[3²+(4-10)²] = √45 m ≈ 6.7082 m

20x = 25 - 65 + 100 = 60  → x = 3 m
20y = 25 - 45 + 100 = 80  → y = 4 m

静止输入下，源 x 与解算 x 的两条水平线应重合在 3 m，源 y 与解算 y 的两条应重合在 4 m；XY 数据集中在 (3,4) m，三个距离分量也各自保持水平。解算器还从所得位置重新计算三个距离，将它们与输入距离逐项相减，输出这三个差的均方根（RMS）：先平方、取平均，再开平方。理想无噪声时，该残差应接近零；实际数据使用 Float32，不能要求所有显示小数位严格为零。

该残差检查“求得的位置能否解释输入距离”。它不是已知真值与解算位置之间的误差，也不是内部线性方程那个本来就可能为零的残差。

本轮产生 64 个位置点。先核对源位置与解算位置是否重合在 (3,4) m，再逐项核对三段距离和残差。

单参数对照：只把 x0 从 3 改为 4 ​

保持其余设置全部不变，尤其保留 y0_m=4、两个速度为零、噪声为零，以及相同锚点。只将坐标发生器的 x0_m 从 3 改为 4 m。

先预测，再运行核对：XY 位置应沿 x 正方向移动 1 m，y 不变；三个距离应成为 √32≈5.6569、√52≈7.2111、√52≈7.2111 m。解算位置应为 (4,4) m，理想距离残差仍接近零。初始 x 变大，并不意味着到每个锚点的距离都变大：它远离 A1，却更接近 A2。

对照下图，位置从 (3,4) m 移到 (4,4) m。再看三根距离柱：到 A1 更远，到 A2 更近，到 A3 的距离也发生变化。

常见问题 ​

现象或疑问检查与解释
XY 出现斜线而不是静止点先检查两个速度是否都显式设为零；非零速度会让位置随时间变化。
距离有三项，为什么只画出一路？三项是同一 item 的分量。标量显示须明确选择下标 0、1、2，不能默认取第一项。
残差小，是否说明真实位置一定准确？不能。若两份锚点采用错误模型，残差不能替代真实坐标的独立核验。
增加噪声后为什么可能失败？模拟器在各距离上叠加独立高斯误差。若出现负测距、无法得到有限位置，或重算 RMS 超过门限，任务会失败。最后有效数据仍可查看，但不是新的位置。
三个锚点能放在同一条直线上吗？重复、共线及近退化站位会在准备时被拒绝；调整残差门限不能解决站位问题。

本课范围 ​

本课只检查局部二维、三个固定锚点的理想软件链路。未包含高度、地球曲率、卫星时钟、大气误差、真实测距硬件或 RTK，也不能据此评价实际无人机定位精度。本课的单参数对照保持噪声为零，先把理想几何关系解释清楚。
