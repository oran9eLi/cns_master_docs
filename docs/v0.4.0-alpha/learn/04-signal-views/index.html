04 同一信号的时域、频谱与瀑布 ​

适用 v0.4.0-alpha。前置：频率、幅度与采样。本课不要求会傅里叶推导。

低空应用问题与学习目标 ​

地面接收的波形可能同时包含多种快慢的变化。时域图复杂时，怎样找出它包含哪些频率？本课把两个已知频率相加，再用三种视图看同一个加法器输出，学会说明每张图回答什么问题。

时域看数值随时间怎样变化；频域看一段样本中不同频率成分的大小；瀑布把连续多帧频谱按时间排起来，看频率成分何时出现或改变。“FFT”是计算频谱的一种快速算法名，先理解输出坐标即可。

接线与参数理由 ​

下载 04-signal-views.cnsproj

text
信号源 1：64 Hz、幅度 1 ──→ 加法器 in1
信号源 2：256 Hz、幅度 0.5 → 加法器 in2
                            out ──→ 时域观察器
                                ├─→ 频谱观察器
                                └─→ 瀑布观察器

两源均为正弦、相位 0、偏置 0、Fs=1024 sample/s。加法器有两输入，同速同类型逐样本相加。工程频谱为 N=1024、周期 Hann、0% 重叠，因此频点间隔 Fs/N=1 Hz，每帧覆盖 1 s，相邻帧也隔 1 s。本例频率落在整数频点，便于读数。

逐步操作 ​

  1. 打开工程，在各观察器“参数”页确认来源都是加法器输出。时域选 out；频谱与瀑布选同节点的频谱来源。瀑布模式在只有一路频谱捕获时选择，多路模式的限制不代表不能运行。
  2. 先设每路 4096 样本，F5。完成后把时域横轴缩到约 0.0625 s，观察慢起伏上叠加较快的变化。
  3. 在频谱中读横轴 Hz、纵轴线性峰值幅度。找约 64 Hz 和 256 Hz 的两个主峰，并记录各自高度。
  4. 为看瀑布持续更新，先停止，设每路样本数 0，再运行。等至少数帧，看同一频率位置是否持续出现条带，再 Shift+F5 停止。
  5. 做单参数练习后，把工程另存；不同运行的瀑布会在新准备时重建，不把它当作长期记录文件。

预期图像及解释 ​

下图把 2048 个样本分成两个 FFT 窗，每行显示一帧频谱。纵轴标记窗口起点，颜色以幅度 1 为参考；64 Hz 和 256 Hz 处各有一条固定频率轨迹。课堂用 4096 个样本会得到四帧，连续运行时会不断加入新帧。

视图输入、坐标和预期
时域加法器 out；横轴 s、纵轴归一化幅度。曲线为两路之和，不再是单一正弦；峰值不一定恰好等于两个幅度相加。
频谱加法器同一路的完整 FFT 帧；横轴 0—512 Hz，纵轴线性峰值幅度。64 Hz 主峰约 1，256 Hz 主峰约 0.5。周期 Hann 会使主峰邻近频点也有能量，不把每个相邻频点都叫作新信号。
瀑布相同来源的连续频谱；频率与时间分别沿标注的两轴，颜色表示相对参考幅度的 dB。固定双音在对应频率形成持续条带，0.5 幅度的条带通常较暗。读实际刻度和色标，不用颜色猜绝对瓦数。

“线性峰值幅度”与功率不同。幅度 0.5 相对幅度 1 的比值为 1/2；按 20×log10(0.5) 为约 −6.02 dB。这里 dB 表示相对比值，不是 dBm，不能直接称作接收功率。

单参数对照 ​

停止，只将信号源 2 的频率从 256 改为 128 Hz，其他参数不动，再运行。预测：64 Hz 的峰是否移动？应保留 64 Hz 主峰，第二个主峰移到 128 Hz、幅度仍约 0.5；瀑布在新运行中显示 64 与 128 Hz 两条带。时域中的快起伏随之变慢。

若希望在同一次连续瀑布中观察条带拐到新频率，可在源属性使用已支持的在线应用，并核对该节点实际回执。修改前后的帧可能跨越切换，不能将回执时刻宣称为精确样本边界。本课的必做对照使用停止重跑，避免误读旧缓存。

常见问题 ​

现象解释与处理
时域看起来像乱线先缩小到几个周期，核对是否仍选加法器的时域输出。
只看到一个峰放大频谱范围，检查源 2 幅度和加法器两条连线，不要改相位来找峰。
瀑布只有几行／更新不快本配置每帧相隔 1 s 样本时间；有限 4096 点只有 4 帧，不靠提高窗口刷新率增加频谱帧。
改 FFT 窗后峰形变了观察设置改变了频谱估计，不代表时域源被滤波。
瀑布像连续画面，是否是动画？每条新频谱来自 worker 的实际窗口计算；没有收到新帧时不能推断产生了新数据。
