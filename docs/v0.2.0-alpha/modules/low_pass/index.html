低通滤波器 ​

适用：v0.2.0-alpha · GNU Radio 3.10.12.0
模块类型：low_pass · 模块定义版本：4

是什么 ​

保留低频成分并衰减较高频率。通过有限长度 FIR 抽头实现，适合去除高频干扰、研究频率选择性，以及为降采样前的带宽限制做准备。

典型接线 ​

混合信号.out → 低通滤波器.in → 观察器。同时观察混合信号和滤波结果，先保持相同采样率，再研究抽取或插值。

下表为内置默认参数下的端口。带路数、元素类型或 vlen 的模块会随参数改变流端口。

方向端口数据类型单位 / 形状
输入in（输入）numeric_f64归一化幅度；vlen=1
输出out（输出）numeric_f64归一化幅度；vlen=1

参数怎么用 ​

输入采样率必须等于上游实际速率，它决定 Hz 与数字频率的对应关系。截止频率附近存在过渡带，不能期待在一条频率线上瞬间从全通过变成全阻断。过渡带越窄，通常需要更长抽头和更多计算。

设计窗影响过渡带与旁瓣取舍；通带增益影响通过部分的大小。抽取与插值不能同时大于 1，输出率按输入率乘插值倍数、再除抽取倍数计算。插值设计使用提高后的设计采样率。

window_param 随设计窗解释：Kaiser 使用 β（≥ 0）；Exponential 使用半窗长度上的衰减 d（dB，≥ 0）；Gaussian 使用 σ（> 0）；Tukey 使用 α（0 ≤ α ≤ 1）。这个参数只对相应四种窗有意义，其他窗不靠它改变。切换窗后按新的含义检查数值，尤其不能给 Tukey 沿用超出 0 到 1 的旧值。

在线修改与重新准备 ​

运行中可在线应用以下字段组；同组字段一起提交：

  • gain、transition_hz、window、window_param、cutoff_hz

其余计算字段需停止并重新准备。在线应用以该节点实际回执为准；编辑草稿本身不会改变已运行的图，旧缓存仍可能包含修改前的数据。

设计参数按组在线应用，关联字段共同确定新抽头。若新设计超过当前滤波历史容量，按提示重新准备。改变速率关系后也须重新准备；比较时避开启动与改参附近的过渡段。

下载与观察 ​

实数信号、分支运算与三种选频滤波 ​

下载 real-processing.cnsproj

在 PC 上打开工程，按 F5 运行。有限运行可将参考源样本数设为 2048 item；重新打开工程后需再次运行以取得数据。

实数信号、分支运算与三种选频滤波

  • 64 Hz 与 768 Hz 混合信号分支进入低通、高通、带通；比较增益、相乘、8 点延时与两抽头 FIR。

实数处理示例将 64 Hz、768 Hz 与噪声的混合信号送入低通。观察输出中 64 Hz 分量保留、768 Hz 分量衰减，并比较相同频率刻度下的幅度。实验来源为本机信号生成。

常见问题 ​

截止频率正确却没有滤掉高频？ 先核对填写的输入采样率与上游是否一致，再检查观察器是否绑定滤波器输出。

抽取后出现新低频？ 检查抽取前是否充分限制带宽，混叠不能靠显示缩放消除。
