03 点少了，正弦就变成三角波了吗？ ​

适用 v0.2.0-alpha。前置：频率与周期，以及除法。

低空应用问题与学习目标 ​

通信设备和计算机不能只存一句“连续变化”，需要按时间取值。本课用一个正弦源观察采样点，区分信号每秒变化几圈与每秒取几个数，并解释为什么稀疏采样的折线会显得有棱角。

把每隔相同时间记录一个数叫作均匀采样。采样率 Fs 的单位是 sample/s，采样间隔为 1/Fs 秒。一个周期里平均有 Fs/f 个样本。本组都是标量，一个 GNU item 就是一个样本；后续向量模块的一个 item 可能含多个分量，应另读其说明。

工程与参数理由 ​

下载 03-sampling.cnsproj

text
信号源 1 out ──→ 观察器：时域（先数点）
             └─→ 观察器：频谱（再核对频率）

初始设置：正弦、幅度 1、频率 64 Hz、相位 0 rad、偏置 0、采样率 1024 sample/s。这样每周期有 1024/64 = 16 点，先建立足够清楚的参照。工程已分别绑定时域与频谱观察器，可按下方步骤核对。频谱保持工程的 N=1024、周期 Hann、0% 重叠；N 是每帧使用的样本数，不是采样率。

逐步操作 ​

  1. 打开工程，核对源参数。先设每路 4096 样本并 F5，完成后在时域观察器用滚轮或时基 + 缩到约四周期，即 0.0625 s。参数页可勾选“曲线样本标记”；显示方式和点数会影响是否逐点画圆点，部分实时曲线只标当前端点。不要用屏幕上的圆点总数推断采样率，可对照下方样本表和参考图数每周期的取样位置。
  2. 若自己创建观察器，在参数页确认信号源 out。频谱使用另一观察器，确认同节点的“频谱”输出，来源路径末尾为 /out/spectrum；不要给时域轴手动改个 Hz 标签冒充频谱。
  3. 记录采样间隔约 0.9765625 ms，一周期 16 点。先预测下方单参练习的结果。
  4. 停止，只将源的采样率改为 256 sample/s，其余不变，再 F5。保持相同的时间范围读图；不要直接比较自动铺满窗口后的线条密度。
  5. 看频谱主峰是否仍在 64 Hz。Fs 变小后每帧的 Hz 间隔也变小，读取新的坐标；不要拿前一轮的频点编号当作 Hz。

第二行把这些点用直线连接后，外观很像三角波。它表示四个离散正弦样本之间的连线，没有新增中间的实际采样值。 信号源仍配置为正弦；不能因为画线有棱角，就宣布源变成了三角波。

这张静态参考图明确标出实际取样位置，线段只是连接相邻样本。右图把两种采样率放在同一时间范围比较；相同的周期不代表取样点同样密。

同样的比例会出现在 Fs=4096 sample/s、f=1024 Hz：4096/1024=4，相位 0 的理想样本仍按 0、+1、0、−1 重复，周期为 0.9765625 ms。这组需要同时改采样率与信号频率，只用于理解等比例情形，不算上面的单参数对照。

频谱为什么仍能有 64 Hz 峰 ​

频谱分析用样本中的重复规律估计频率，不把画面上每一段直线当成真实连续信号。本例 64 Hz 小于 Fs/2，且满足本例理想单音条件，所以四点一周期仍可出现正确的主峰；时域图“圆不圆”与频率是否正确不是同一个问题。

对于没有混叠、频带受限的理想低通信号，采样率须严格大于最高信号频率的两倍，实际采集还要留过渡带并在采样前限制带宽。这个条件不等于“两点足够看清波形”，也不能只检查当前最明显的主峰而忽略噪声及其他频率。本课不连接真实模数转换器，不能验证硬件抗混叠能力。

采样后不同的连续信号可能得到同样的样本，这叫混叠。发布版源参数校验限制频率范围，不要用输入非法频率的方式强行完成混叠演示。

常见问题 ​

现象先检查
点很密，看不到标记缩小时间范围，别只把窗口拉大。
采样率变小后同样样本数跑更久实验时长是样本数除以 Fs；4096 点在 256 sample/s 下代表 16 s 的样本时间。
频谱没有出现一帧要满 N 个样本；少于 1024 点不能生成本配置的完整帧。
相位不同，开头不再是 0、1、0、−1对照表明确以相位 0 为前提，恢复相位后重跑。
想通过拖慢显示补出更多点显示速度不增加采样信息；本课应调整真实 Fs，不能伪造中间点。
