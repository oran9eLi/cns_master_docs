06 保留需要的变化：低通滤波能做什么？ ​

假设机地通信的某个处理环节需要保留缓慢变化的信号，却混入了较快的周期干扰和随机噪声。能否按“变化快慢”筛选？本课先规定 64 Hz 是要保留的成分，768 Hz 是要衰减的成分，再观察低通滤波器的作用。

适用 CNS Master v0.2.0-alpha。先完成05 信号与噪声。本例是选频原理仿真，64 Hz 不代表无人机的位置更新率，也不代表无线电载频。

下载本课工程：06-filter.cnsproj

学习目标与必要知识 ​

完成后应能在频谱上指出被保留、被衰减的成分，并说明“看起来更平滑”为什么还不够。

低通表示较低频率较容易通过、较高频率受到衰减。截止频率标示选频边界附近的位置；真实有限长度滤波器有一段过渡带，通过与阻挡不会在一条竖线上瞬间切换。衰减表示幅度减小，不保证变为严格的零。

接线与参数理由 ​

text
信号源 1：64 Hz  ──→ 加法器 1.in1
信号源 2：768 Hz ──→ 加法器 1.in2
噪声源 1        ──→ 加法器 1.in3
                         out ──→ 低通滤波器 1.in

混合输出和滤波输出都保留观察支路。观察支路只取数，不改变主链计算。

位置本课值为什么选它
信号源 1正弦 64 Hz，幅度 1，初相 0，偏置 0需要保留的低频参照
信号源 2正弦 768 Hz，幅度 0.5，初相 0，偏置 0与低频相隔较远，便于看清选频效果
噪声源 1高斯，幅度 0.1，固定种子 7加入较小的随机扰动
三个源及低通输入采样率4096 Hz保持同速；最高的 768 Hz 低于 2048 Hz 奈奎斯特频率
加法器 1输入路数 3将三路相加
低通滤波器 1截止 256 Hz，过渡带宽 128 Hz，通带增益 1，Hamming 设计窗64 Hz 远低于边界，768 Hz 远高于边界，避免一开始就在过渡带争论“通过多少”
抽取、插值均为 1本课不改变采样率，只研究选频

Hamming 是设计滤波系数的一种窗，本课保持工程内设置。它与观察器计算频谱时使用的窗是两个用途不同的设置，不必把两者改成同一个名字。

逐步操作 ​

  1. 下载工程，先按 Shift+F5 停止已有本地任务，再用 Ctrl+O 打开文件。核对连线以及两个信号源的编号和频率。
  2. 在运行前写下预测：混合输出应该有哪两个主要谱峰？经过低通后，哪一个应明显减小？
  3. 按 F5。工程中的观察器已绑定滤波前后输出。在“参数”页确认时域捕获为“加法器 1 → 输出”和“低通滤波器 1 → 输出”；另有两个独立频谱窗口，分别捕获这两个节点的“频谱”。
  4. 若自行绑定，从“编辑 → 插入 → 观察器”打开工具，在参数页逐项点选候选。两路时域可放在同一个观察器。两个频谱也支持同窗叠加，或像下载工程一样各开一窗；不将时域与频谱混在同一图。瀑布模式需要恰好一路频谱。
  5. 先看频谱，横轴显示 0—2048 Hz，两路采用相同幅度刻度。找到 64 Hz、768 Hz，比较同一频率处滤波前后的高度，不只比较各自最高的峰。
  6. 再看时域“曲线叠加”。把全宽缩到约 0.0625 s，观察较慢的周期骨架及其上的快速起伏。滤波后可能有时间滞后，启动初段也有过渡；不要拖动一条曲线把它强行对齐。
  7. 等待稳定数据后按 Shift+F5。需要细看时可拖动图像回看；“自动刻度”恢复最新数据。将工程另存为自己的练习文件，记录保留、衰减的频率及坐标单位。

预期图像与解释 ​

左图比较滤波前后，开头的一段变化是滤波器的启动过程。右图比较两个截止频率下的输出。按下面步骤再看稳定后的频谱，判断哪些频率分量被保留、哪些被减弱。

混合频谱应能辨认 64 Hz 与 768 Hz 两个主要成分，噪声还会形成起伏的背景。低通输出在 64 Hz 附近仍有明显谱峰，768 Hz 附近则明显减小；不要要求峰高恰好等于输入参数，也不要把有限数值误差当作异常。

时域中，滤波输出更接近缓慢变化的正弦，但这只是与本课目标一致的外观。判断依据是：64 Hz 成分保留、768 Hz 成分受到衰减。低通也会放过一部分低频噪声，无法把所有噪声都删除。若需要的信息本来就在高频，盲目低通也会把有用成分一起损伤。

滤波器需要利用相邻样本，会带来延迟和启动过程。两路同一横坐标不保证代表已经补偿过延迟的同一波峰；本课不据两条曲线的逐点相减计算误差。

单参数对照：把截止频率放宽到 1024 Hz ​

  1. 停止运行，只把低通滤波器的“截止频率”由 256 改为 1024 Hz。过渡带宽仍为 128 Hz，其他参数和连线保持不变。
  2. 按 F5 重新运行，使用同样的频谱范围和纵轴刻度。
  3. 查看 768 Hz 附近是否重新出现明显谱峰。解释：这一成分没有改变，是滤波器允许通过的范围变宽了。
  4. 恢复截止 256 Hz，再重新运行核对。

请完成一句话：“截止频率越高，_______，所以不一定滤得越干净。”可填“允许通过的高频范围越宽”，再联系你看到的 768 Hz 成分解释。

常见问题 ​

现象检查方法
滤波前后完全相同检查是否绑定到同一个输出，以及运行快照中的截止频率是否为本轮值
准备提示速率不一致三个源和滤波器输入采样率均应为 4096；不要通过只改滤波器 Fs 来移动边界
768 Hz 仍有很小的值有限 FIR、噪声和有限长度频谱不会保证严格零；比较同刻度下的衰减程度
滤波输出波峰位置较晚先考虑滤波延迟与启动过渡，不把它直接称为网络延迟或丢包
只看见一个周期，无法读数放大横轴范围查看几个周期；缩放显示不会改变实际计算参数

到这里，你已经用“时间上怎样变”和“包含哪些频率”两种方式解释同一数据。下一课用两个坐标理解 I/Q，为相位与数字星座建立直觉。
